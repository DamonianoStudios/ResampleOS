# ResampleOS 0.1.2

Automation for every loop, spun-metal knobs, and a demo track made entirely from ResampleOS's own sounds. Projects from 0.1.1 open as they were.

![The Automation tab, with the demo's filter sweep](https://raw.githubusercontent.com/DamonianoStudios/ResampleOS/v0.1.2/docs/images/automation.png)

> **Pre-release.** Developed and tested on Windows 11 only. Expect rough edges, and save often.

## New

- **Automation.** Move a control through a loop: a filter opening over the intro, an echo thrown on the last beat, the master fading at the end. Bus effect knobs and EQ sliders, bus levels and pans, and each pad's volume, pan and filter cutoff can all be automated.
- **Per loop.** Each loop keeps its own automation, which switches with the loop on the beat and is saved and undone with it.
- **Two ways in.** Right-click a control and choose **Automate**, then draw the lane in the new **Automation** tab (click to add a point, drag to move it, right-click to delete it, with snap to the grid). Or turn on **Rec**, press play and move the control: the move is written in as the playhead passes.
- **Built-In Boom Bap.** A two-minute demo track made only from the drum synth, the internal synths and the built-in effects, with automation in every loop. It ships in the download: open the `showcase/built-in-boom-bap` folder from **File > Open project…** and press `Space`.

## Improved

- **Knobs.** Every knob now has a spun-metal cap: fine circular grooves that catch the light in a cross, a bevelled edge and a knurled rim, with an engraved pointer in the control's colour.
- **Drum synth display.** The labels of the two handles no longer write over each other when the handles are close together.

## Install

**From the download:** unzip `ResampleOS-0.1.2-windows-x64.zip` and run `resampleos.exe`. There is no installer and nothing is written outside the folder except settings in `%APPDATA%\ResampleOS`. Windows may show a SmartScreen warning because the program is not signed: choose **More info**, then **Run anyway**. If it reports a missing `VCRUNTIME140.dll`, install the [Microsoft Visual C++ Redistributable](https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist).

**Upgrading from 0.1.1:** replace the folder. Settings and projects carry over. A project saved in 0.1.2 still opens in 0.1.1, but without its automation.

**From source:** you need [Rust](https://rustup.rs) 1.88 or newer and the MSVC build tools.

```bash
git clone https://github.com/DamonianoStudios/ResampleOS
cd ResampleOS
cargo run --release -- showcase/built-in-boom-bap
```

Press **F1** in the app for the shortcuts. The [user guide](https://github.com/DamonianoStudios/ResampleOS/blob/v0.1.2/docs/USER_GUIDE.md) covers everything in the order you meet it, including the new **Automation** section.

## Known limitations

- Windows only for now. The code uses cross-platform libraries but has not been built or run on macOS or Linux.
- VST3 only: no VST2, CLAP or AU.
- Automation covers the built-in bus effects, bus levels and pans, and pad volume, pan and cutoff. Drum synth knobs and hosted plugin parameters cannot be automated yet, and lanes are straight lines between points.
- Automated controls keep showing where they were set by hand; a dot marks that automation is moving them.
- Some VST3 effects load and show their editor but pass no audio (three of fourteen vendors in testing). A silent effect mutes its bus.
- A hosted plugin that crashes takes the app with it; only scanning is isolated.
- Changing the audio device, sample rate, buffer size or skip-back length needs a restart.
- The drum synth's factory sounds and the demo track were balanced by measured level; they have not been tuned by ear.
- Vocal input latency is set by hand; there is no automatic measurement. Monitoring through the app is only as fast as shared-mode Windows audio allows.
- Pitch Lock is for one dry voice. Harmonies, doubles or a vocal with reverb already on it give it no single pitch to follow.
- Vocal recording, pitch correction and the vocal effects were tested with imported audio and test signals, not with a live microphone.
- The piano roll's toolbar wraps onto a second row in a small window, leaving the grid short. It is comfortable maximised.
- Projects store each pad's active take, not its whole take stack.
- Hardware controllers get no LED feedback.
