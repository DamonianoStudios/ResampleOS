# ResampleOS 0.1.0

The first public release of ResampleOS, a pad-based DAW built around committing to audio: chop, resample, bake, repeat. It takes the hardware-sampler workflow and gives it unlimited banks, a piano roll, a step sequencer, vocal takes, plugin hosting and a capture buffer that never stops recording.

![ResampleOS playing a project](https://raw.githubusercontent.com/OWNER/ResampleOS/v0.1.0/docs/images/demo-play.gif)

> **Pre-release.** Developed and tested on Windows 11 only. Expect rough edges, and save often.

## Highlights

- **Pads and banks.** A 4×4 pad matrix per bank, 64 banks, with 8×8 and 16×16 overviews.
- **Resample to a pad.** Arm, hit a destination pad, perform, and the result is baked onto that pad, bus effects and all. With the transport running, takes start on the downbeat and are trimmed to whole bars.
- **Skip-back.** The last five minutes of output are always in memory. Pull the last 16 bars onto a pad with one key, or drag a selection from the top-bar waveform onto a pad.
- **Take stack.** Every destructive edit (crop, reverse, normalize, pitch, conform, baked effects) is a new take, 16 per pad.
- **Key and tempo conform.** Samples are analysed on load; one action stretches and re-pitches them to the project, transients intact.
- **Transient chop.** One key spreads a sample's slices across the next empty bank.
- **Piano roll and step sequencer.** Scale lock, velocity lane, free microtiming, swing and humanize.
- **Loops, chain and perform mode.** Up to sixteen loops of 1 to 16 bars over the same pads, chained into an arrangement or launched live from the pads.
- **Vocal takes.** A vocal pad records a take each time round the loop. Swipe to comp, cut, move and slip clips, add doubles, and bake the result to a pad or to a bank of phrases.
- **Six buses.** Four performance buses, a vocal bus and a master, three effect slots each, with pan, routing into later buses and sidechaining.
- **Built-in effects.** Vinyl, cassette, 3-band EQ, DJ isolator and filter, bit-crush, compressor, tape delay, reverb, scale-locked pitch correction, a vocal compressor and a dub throw.
- **VST3 hosting.** Instruments on pads and effects on buses, with working plugin editors and meters.
- **Mod / Warp.** Per-pad filter, pitch and a tempo-synced LFO, straight, dotted or triplet down to 1/32.
- **External input, MIDI controllers, project-wide undo and redo, Stop All.**

## Install

**From the download:** unzip `ResampleOS-0.1.0-windows-x64.zip` and run `resampleos.exe`. There is no installer and nothing is written outside the folder except settings in `%APPDATA%\ResampleOS`. Windows may show a SmartScreen warning because the program is not signed: choose **More info**, then **Run anyway**. If it reports a missing `VCRUNTIME140.dll`, install the [Microsoft Visual C++ Redistributable](https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist).

**From source:** you need [Rust](https://rustup.rs) 1.88 or newer and the MSVC build tools.

```bash
git clone https://github.com/OWNER/ResampleOS
cd ResampleOS
cargo run --release
```

Press **F1** in the app for the shortcuts. The [user guide](https://github.com/OWNER/ResampleOS/blob/v0.1.0/docs/USER_GUIDE.md) covers everything in the order you meet it.

## Known limitations

- Windows only for now. The code uses cross-platform libraries but has not been built or run on macOS or Linux.
- VST3 only: no VST2, CLAP or AU.
- Some VST3 effects load and show their editor but pass no audio (three of fourteen vendors in testing). A silent effect mutes its bus.
- A hosted plugin that crashes takes the app with it; only scanning is isolated.
- Changing the audio device, sample rate, buffer size or skip-back length needs a restart.
- Vocal input latency is set by hand; there is no automatic measurement. Monitoring through the app is only as fast as shared-mode Windows audio allows.
- Pitch Lock is for one dry voice. Harmonies, doubles or a vocal with reverb already on it give it no single pitch to follow.
- Vocal recording, pitch correction and the vocal effects were tested with imported audio and test signals, not with a live microphone.
- The piano roll is cramped in a small window, where its toolbar wraps onto a second row. It is comfortable maximised.
- Projects store each pad's active take, not its whole take stack.
- Hardware controllers get no LED feedback.
