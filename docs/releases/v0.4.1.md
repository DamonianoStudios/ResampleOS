# ResampleOS 0.4.1

A small update to 0.4.0: step patterns go to the piano roll, ResampleOS asks before closing with unsaved work, and the sends menu behaves.

> **Pre-release.** Developed and tested on Windows 11 only. Expect rough edges, and save often.

## New

- **Steps to the piano roll.** Right-click a pad's name on the left of the step sequencer. For a drum or MIDI pad, **Open in piano roll** opens its pattern there. For an audio pad, **Convert to piano roll MIDI** moves its steps, in every loop and on the song timeline, to a new MIDI pad that plays the sample chromatically. Each step becomes a note at the sample's own pitch, ready to move up and down. The audio pad keeps its sample and settings, and the new pad plays through its bus, effects and sends. Undo puts it back.
- **Asking before closing.** Closing ResampleOS with unsaved changes asks **Would you like to save?** **Save** saves (asking for a folder if the project has none) and closes. **Don't Save** closes without saving, and **Cancel** goes back to the project. Restarting from Preferences carries the project across without asking.

## Fixed

- In the **Sends** menu, a double-click on a slider closed the menu instead of turning that send off. The menu now stays open while you work in it, a double-click turns the send off, and an **Off** button beside each slider does the same.

## Install

**From the download:** unzip `ResampleOS-0.4.1-windows-x64.zip` and run `resampleos.exe`. Windows may show a SmartScreen warning because the program is not signed: choose **More info**, then **Run anyway**. If it reports a missing `VCRUNTIME140.dll`, install the [Microsoft Visual C++ Redistributable](https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist).

**Upgrading from 0.4.0:** replace the folder. Settings, projects and the sample browser's analysis carry over, and projects open the same in both versions.

See the [0.4.0 release notes](v0.4.0.md) for sends, the sample browser's analysis and filters, and the rest of 0.4, and the [user guide](https://github.com/DamonianoStudios/ResampleOS/blob/v0.4.1/docs/USER_GUIDE.md) for how it all works.
