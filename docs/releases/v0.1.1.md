# ResampleOS 0.1.1

A built-in drum synth, a mixing-console look for the buses, a piano roll you can zoom into, and patterns up to sixteen bars in the step sequencer. Projects from 0.1.0 open as they were.

![The drum synth on a pad, with a full 808 kit on the bank](https://raw.githubusercontent.com/DamonianoStudios/ResampleOS/0.1.1/docs/images/drum.png)

> **Pre-release.** Developed and tested on Windows 11 only. Expect rough edges, and save often.

## New

- **Drum synth.** A pad can now make its own drum sound instead of playing a sample. Five engines (Sub / Kick, Snare / Clap, Metallic / Hat, FM / Tom / Perc and Modal) each play through eight macro knobs, with 32 factory sounds to start from.
- **Drum kits.** Right-click a bank tab and load a whole 16-pad kit: 808 Analog, 909 Analog, Boom Bap, Lo-Fi Dust, FM Perc, Physical / Modal or Glitch / Noise. Each kit's closed and open hats choke each other.
- **Velocity and random per knob.** Every macro has its own amount that a hard hit pushes it by, and its own range that it wanders by on each hit, shown as rings around the knob.
- **Step locks.** `Alt`+click a drum step in the step sequencer to lock knob values to that step only: a longer hat on step 7, a higher tom on step 12.
- **Bake and come back.** `Ctrl+B` renders a hit to a take; `Ctrl+M` varies the knobs a little and bakes the result. A baked take remembers the synth that made it, so **Edit synth** (or stepping back past the first take) brings the knobs back exactly as they were.
- **Key lock and synced tails.** A drum can be tuned to the project key, and its tail cut on a note value at the project tempo so a long kick never runs into the next one.
- **Drum pads at a glance.** Pads show what kind of drum they hold and how long it rings, and the 16×16 overview shows each drum as an icon.

## Improved

- **Bus strips like a console.** Each bus has a long fader with its meter at the right of its effects, and its output under them.
- **Piano roll.** Bars and beats are numbered along the top (1.1, 1.2, 1.3 …). `Ctrl`+scroll zooms in, `Shift`+scroll or the new scroll bar moves along, and **Follow** keeps the playhead in view while playing.
- **Step sequencer.** Patterns run from 1 to 16 bars, shown four bars at a time, with **Follow** to turn the page as it plays. Bar numbers sit under the grid.
- **Chain.** Drag a loop in the chain to move it; no more clearing it to change the order.
- **Stereo meters.** In a tall window, a stereo image and phase correlation meter sit under the pads.
- **Clearer piano roll grid.** **Ghosts** no longer draws other pads' transient markers across the grid; it shows only the other MIDI pads' notes.

## Install

**From the download:** unzip `ResampleOS-0.1.1-windows-x64.zip` and run `resampleos.exe`. There is no installer and nothing is written outside the folder except settings in `%APPDATA%\ResampleOS`. Windows may show a SmartScreen warning because the program is not signed: choose **More info**, then **Run anyway**. If it reports a missing `VCRUNTIME140.dll`, install the [Microsoft Visual C++ Redistributable](https://learn.microsoft.com/cpp/windows/latest-supported-vc-redist).

**Upgrading from 0.1.0:** replace the folder. Settings and projects carry over. A project saved in 0.1.1 with drum pads in it will not open in 0.1.0.

**From source:** you need [Rust](https://rustup.rs) 1.88 or newer and the MSVC build tools.

```bash
git clone https://github.com/DamonianoStudios/ResampleOS
cd ResampleOS
cargo run --release
```

Press **F1** in the app for the shortcuts. The [user guide](https://github.com/DamonianoStudios/ResampleOS/blob/0.1.1/docs/USER_GUIDE.md) covers everything in the order you meet it, including the new **Drum synth** section.

## Known limitations

- Windows only for now. The code uses cross-platform libraries but has not been built or run on macOS or Linux.
- VST3 only: no VST2, CLAP or AU.
- Some VST3 effects load and show their editor but pass no audio (three of fourteen vendors in testing). A silent effect mutes its bus.
- A hosted plugin that crashes takes the app with it; only scanning is isolated.
- Changing the audio device, sample rate, buffer size or skip-back length needs a restart.
- The drum synth's factory sounds were balanced by measured level and length; they have not yet been tuned by ear.
- Drum macros have no MIDI controller mapping, and the Modal engine is struck by noise only (it cannot yet borrow a sample as its strike).
- Vocal input latency is set by hand; there is no automatic measurement. Monitoring through the app is only as fast as shared-mode Windows audio allows.
- Pitch Lock is for one dry voice. Harmonies, doubles or a vocal with reverb already on it give it no single pitch to follow.
- Vocal recording, pitch correction and the vocal effects were tested with imported audio and test signals, not with a live microphone.
- The piano roll's toolbar wraps onto a second row in a small window, leaving the grid short. It is comfortable maximised.
- Projects store each pad's active take, not its whole take stack.
- Hardware controllers get no LED feedback.
